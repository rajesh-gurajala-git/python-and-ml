creating Circle class:

class Circle(object):
	brand = "Honda"
	def __init__(self, r, c):
		self.radius = r
		self.color  = c
		
	def add_radius(self, x):
		self.radius = self.radius + x
		return self.radius
		
	# u can make a new attribute with a method
	def add_cap(self, cap):
		self.capacity = cap
		
		
		
c1 = Circle(5, "Blue")
c2 = Circle(82, "Yellow")
c1.radius = 11
c1.add_cap(250)

FILE HANDLING IN PYTHON

We will use python built-in open function to create a file object and obtain data from a txt file.

1. READ FILE

file1 = open("/resources/idx.txt", "r") => ARG: (FILE_LOCATION, MODE) (r = read, w = write, a = append)

methods, attributes of file1:
file1.name	'/resources/idx.txt'
file1.mode	'r'
file1.close()	instead of using close() evrytime, we do [ with open("...") ] which closes file automatically

with open("resources/idx.txt") as file1:
	file_stuff = file1.read()
	print(file_stuff)		# PRINTS FILE CONTENT !!
print(file_stuff)			# VALID !!

now file_stuff contains entire content in a string, to get content as array of string where each string is of each line,
with open("/idx.txt") as file:
	stuff = file.readlines()
print(stuff)		# ["line 1 \n", "line 2 ... \n"]

Also to get line by line,
with open("/a.txt") as file1:
	for line in file1:
		print(line)
