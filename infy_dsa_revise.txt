1. BINARY TREES:

i.) Iterative pre order traversal: root, left, right
	=> print(root), st.push(left), st.push(right)
	
ii.) Iterative in order traversal: left, root, right
	=> cant simply push {left, root(for right)} as again encounter root, we can't decide to use left or not.
	=> with curr pointer = root, [push curr into stack, go curr = curr->left] and at curr = null;
	=> curr = st.top(), print(curr), go curr = curr->right.
	=> REPEAT same process, stop when curr = null and st is empty.
	
iii.) Iterative post order: left, right, root
	1. TWO STACK: left, right, root
		=> st.push(left), st.push(right), result.push(root)
		=> Finally, reverse result and return result
		
	2. ONE STACK: left, right, root
		=> curr = root
		=> while curr != null AND st not empty
			if curr: st.push(curr), go to [curr = curr->left]
			else:
				temp = st.top(), st.pop()
				if temp->right exists: curr = temp->right
				else:
					print(root)
					while(st.top()->right == temp):
						print(st.top())
						temp = st.top()
